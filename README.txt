SHARK FIT Android project

This project builds a debug APK using GitHub Actions.

1. Upload the contents of this folder to a new GitHub repository.
2. Open the repository's Actions tab.
3. Enable GitHub Actions if asked.
4. Run the workflow named "Build SHARK FIT APK" using Run workflow.
5. Open the completed workflow run and download the "SHARK-FIT-debug-APK" artifact.
6. Extract the ZIP artifact and install app-debug.apk on your Android phone.

The first build may take several minutes. This is a debug APK for personal testing.
